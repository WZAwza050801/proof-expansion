**证明结构概览**。本证明的目标是：对给定的素数 p 与整数列 a_1, …, a_{2p−1} ∈ F_p，证明存在 p 个下标 I 使得 Σ_{i∈I} a_i ≡ 0 (mod p)。证明的整体思路如下：

1. 首先，我们引入 2p−1 个变量 x_1, …, x_{2p−1}；
2. 其次，我们构造两个多项式，将"选择 p 个元素且其和为 0"的问题编码为多项式的公共零点问题；
3. 再次，我们利用计数定理完成证明；
4. 最后，我们回到原命题，得出结论。

下面逐步展开。

**步骤一：构造多项式。** 定义两个多项式：

f(x) = x_1^{p−1} + x_2^{p−1} + ⋯ + x_{2p−1}^{p−1} = Σ_{i=1}^{2p−1} x_i^{p−1}，

g(x) = a_1 x_1^{p−1} + a_2 x_2^{p−1} + ⋯ + a_{2p−1} x_{2p−1}^{p−1} = Σ_{i=1}^{2p−1} a_i x_i^{p−1}。

众所周知，这样的多项式在有限域上具有良好的性质，为后续的计数分析奠定了基础。

**步骤二：分析公共零点的含义。** 容易验证，由依赖 D2，对每个 i，x_i^{p−1} 的取值只有两种可能：x_i ≠ 0 时 x_i^{p−1} = 1，x_i = 0 时 x_i^{p−1} = 0。因此，x_i^{p−1} ∈ {0, 1}，且 x_i^{p−1} = 1 当且仅当 x_i ≠ 0。显然，f(x) ≡ 0 (mod p) 当且仅当 #{i : x_i ≠ 0} ≡ 0 (mod p)；又显然该个数位于区间 [1, 2p−1] 内，故该个数恰为 p。另一方面，g(x) ≡ 0 (mod p) 当且仅当 Σ_{x_i ≠ 0} a_i ≡ 0 (mod p)。综上可知，方程组的非零公共解与"和为 0 (mod p) 的 p 元子集"一一对应。换言之，只需证明非零公共解存在。

**步骤三：应用计数定理。** 不难验证，deg(f) = p − 1，deg(g) = p − 1，故 deg(f) + deg(g) = 2p − 2 < 2p − 1。显然，这满足依赖 D1 的度数条件，因此公共零点总数 N 满足 N ≡ 0 (mod p)。另一方面，显然 (0, 0, …, 0) 是方程组的一个公共零点，故 N ≥ 1。结合 N ≡ 0 (mod p)，可知 N ≥ p > 1，从而必存在非零公共解。

**结论。** 综上所述，我们证明了：对任意素数 p 与任意整数列 a_1, …, a_{2p−1} ∈ F_p，存在 p 个下标 I，使得 |I| = p 且 Σ_{i∈I} a_i ≡ 0 (mod p)。原命题得证。∎
