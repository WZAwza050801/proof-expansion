# 写手提示词 v0.4 重写方向说明（STAGE-1 1.4）

- 日期：2026-08-18
- 状态：方向说明（本阶段**不冻结** v0.4 草稿；冻结留待新评分在阶段 4 校准后）
- 对象：`prompt-skill-writer.md`（v0.2-dev）与 `prompt-skill-writer.v0.4-draft.md`（v0.4 草稿）的下一版方向
- 依据：`experiment-design.md` v2 §1/§6；`prompt-gpt56sol-reviewer.md` v2；Seidel charter §5/§7（桌面 `seidel_conjecture_distilled_work_charter.md`）

## 1. 为什么必须重写

v0.2/v0.4-draft 的核心纪律是"**诚实→停止**"：无法确认关键推理 → 停止硬补 → 标 `unverified` 进缺口账本。这条规则在 v1 评分（H 占 35%）下"得分"，在 v2 评分下**恰是失败模式**：

- v2 主指标是补全度 G（骨架步 completion test 闭合多少）、严谨性 R、可读性 L；
- "诚实停下"现在对应失败模式 `lazy_stop`（本可用题目包资源推进却过早放弃）；
- v0.4-draft 的 B4（"标缺口后闭环，继续完成无关部分"）方向正确，但整套"账本/清单"结构在 v2 的 L2（凑格式重复）子项下天然失分，且其"审计感"正是要反的"AI 味"来源。

重写方向一句话：**把"诚实→停止"改成"诚实→推进"**——先补能补的部分，再精确报告最小 blocker 与最强已证定理。

## 2. 逐条重写方向（下一版 B 必须落实）

### W1. 第一反应从"停止"改为"推进"

- 删除 v0.2 第 0 节第 4 条"无法确认关键推理时，停止硬补"作为首要规则。
- 改为：遇到推不动的步 → ① 先尝试由题设＋已给依赖＋定义级运算（直接代入、反证、有限和交换、变量替换、空和约定等）自己证明，记下试过的路径与卡点（v0.4-B1 保留并提前为第 4 条的首要动作）；② 确认确实需要包外定理/事实后，才允许把该步标 BLOCKED；③ 不依赖该步的其余骨架步继续做到底。

### W2. 六态 claim 取代"given/unverified 二元 + 账本"（采纳 charter §5）

- 每个承重断言内联标注六态之一：`FIXED`（题目给定目标/约定）/ `IMPORTED-VERIFIED`（引用允许依赖且前提已核）/ `PROVED-IN-PROJECT`（本证明完整证明）/ `CONDITIONAL`（精确写出的未证输入下成立）/ `CANDIDATE`（提议的构造或策略，尚未建立）/ `BLOCKED`（精确障碍，附最小 blocker）。
- 与 v0.4-B2 的"标签-账本一一对应"原则等价：标签内联在断言上，账本（如有）只是索引，不允许孤儿标签。
- 六态的目的不是审计表演，而是让"哪些已证、哪些悬置"在正文里一目了然——直接服务 R（严谨性）与 G（补全度）的核验。

### W3. 最小 blocker ＋ 最强已证定理（采纳 charter §7 最后一条）

- 补不动时输出两样：**最小 blocker**（一句精确障碍：缺哪个事实/哪个引理/哪个条件）＋**最强已证定理**（在已闭合部分上实际证明了什么）。
- 禁止输出"完整但伪造"的证明；同样禁止输出"整体放弃"的证明（后者现在也是失败模式 `lazy_stop`）。

### W4. 写作纪律（采纳 charter §7 蒸馏，直接服务 L 维度）

1. 一个证明只回答一个主问题；不复述题目包背景；
2. 不使用"证明前检查/缺口账本/审阅清单"等工作流词汇与栏目——只写数学正文；
3. 详细计算只出现在承重处（构造、符号、计数、估计）；例行步骤一笔带过；
4. 自然段推进；公式与解释文字配比适度；不用"显然/易见/众所周知/综上所述"填充；
5. 保守专业的数学文风。

### W5. 输出形态（初案，供 v0.4 冻结时定稿）

- B 的输出 = **自然证明正文**＋承重断言内联六态＋（仅在确有 blocker 时）文末一段 blocker 说明。
- 不再强制"证明前检查/分步模板/缺口账本/审阅清单"四段结构（该结构在 v2 下无加分、在 L2 上失分）。
- 内联六态只标在承重断言上（全篇 ≤ 十余处），不标例行步骤——防止标注本身变成新格式。
- 反泄露条款照旧适用：judge 不得因标注的有无打分；确定性格式检查器也不再检查 B 的栏目完整性（栏目已取消）。

### W6. "何时该停、何时必须继续"的边界（本说明的验收核心，写死）

**必须继续（不继续 = lazy_stop）**：

1. 该骨架步可由题设＋已给依赖＋定义级运算闭合——未穷尽这些手段前不得停下；
2. 缺口不阻断的独立部分（其余骨架步、归纳的其它分支、构造的其余组件）——必须继续到全部闭合；
3. 一个依赖不适用时——先检查其余依赖与题设本身，确认全都不适用才能停。

**该停（继续 = 伪造）**：

1. 已列出至少一条由题设出发的尝试路径且写明卡点，且确认所需事实确实在包外——此时标 BLOCKED＋最小 blocker，把该步及依赖它的结论标 CONDITIONAL；
2. 定理陈述与骨架/依赖发生冲突——不得自行挑一种解释，按冲突报告（保真条款保留）；
3. 结论需要超出原命题范围的假设——不得偷加假设补完。

**边界判定口诀**：停下的理由只能是"包外事实确实缺失"或"输入自相矛盾"；否则都必须继续。停下时必须交回"最强已证定理"。

### W7. 条件 A 同步改（1.4 一并定方向）

- A 的下一版也从"普通证明任务说明"改写为"**补全任务说明**"：给定脊柱与允许依赖，补成完整、严谨、可读的证明——但不含六态、blocker 报告与写作纪律五条（这些正是被测干预）。
- 这样 A/B 的差异才落在"推进纪律"上，而不是落在"任务是否被正确描述"上。
