# Erdős–Ginzburg–Ziv 定理（分块撰写流水线演示）

## 记号约定

- $n$：正整数；2n−1 为给定整数个数
- $F_p$：模 p 的剩余类域（p 素数）；多项式在其上时系数与取值按模 p 理解
- $a_1,...,a_{2n−1}$：给定的 2n−1 个整数
- $D1$：计数定理：设 p 素数，f_1,...,f_r 为 F_p 上 m 元多项式且 Σ deg(f_i) < m，则公共零点数 N ≡ 0 (mod p)
- $D2$：幂取值：x ∈ F_p 时 x^(p−1) ∈ {0,1}，且 =1 当且仅当 x ≠ 0
- $D3$：整除算术：(a) S 被素数 p 整除 ⇒ S = p·c；(b) S 被 n = p·m 整除且 S = p·c ⇒ c 被 m 整除

## B1 素数情形

设 p 为素数，给定 2p−1 个整数 a_1,…,a_{2p−1}，将其像仍记作 a_i ∈ F_p。在 F_p 上取变量组 x = (x_1,…,x_{2p−1})，定义两个多项式
f(x) = Σ_{i=1}^{2p−1} x_i^{p−1}，　g(x) = Σ_{i=1}^{2p−1} a_i x_i^{p−1}。
二者次数均为 p−1，故 Σ deg = 2p−2 < 2p−1 = m（变量个数），D1 的度数条件满足；由 D1，公共零点个数 N = |{ x ∈ F_p^{2p−1} : f(x) = g(x) = 0 }| 满足 N ≡ 0 (mod p)。显然 (0,…,0) 是公共零点，故 N ≥ 1；又 N 是 p 的倍数（D1）且 p ≥ 2，得 N ≥ p ≥ 2，于是存在非零公共解 x ≠ 0。

取任一非零公共解 x。由 D2，x_i^{p−1} ∈ {0,1} 且 x_i^{p−1} = 1 ⟺ x_i ≠ 0，故 f(x) 等于支撑集 supp(x) = { i : x_i ≠ 0 } 的基数在 F_p 中的像；f(x) = 0 即 |supp(x)| ≡ 0 (mod p)。因 x ≠ 0 有 1 ≤ |supp(x)| ≤ 2p−1，故 |supp(x)| = p。此时 g(x) = 0 即 Σ_{i∈supp(x)} a_i ≡ 0 (mod p)。反向：若 I ⊆ {1,…,2p−1} 满足 |I| = p 且 Σ_{i∈I} a_i ≡ 0 (mod p)，令 x_i = 1 (i ∈ I)、x_i = 0 (i ∉ I)，则 f(x) = p ≡ 0、g(x) = Σ_{i∈I} a_i ≡ 0，得非零公共解。故映射 supp 给出 {非零公共解} → {和为 0 (mod p) 的 p 元下标子集} 的满射，且在指示向量解上与其逆（I ↦ χ_I）一一对应，非零公共解的存在性恰等价于这类子集的存在性。结合 N ≥ 2，存在 p 元子集 I 使 Σ_{i∈I} a_i ≡ 0 (mod p)，即存在 p 个整数其和为 p 的倍数。


## B2 合成情形

对任意给定的 2pm−1 个整数施行下述三步。

第一步（分组计数）。反复调用由块1的结论：任意 2p−1 个整数中存在 p 个其和 ≡ 0 (mod p)。设已从剩余数中抽得 j 组，则剩余 2pm−1−jp 个数；只要剩余个数 ≥ 2p−1 即可再抽一组。当 j ≤ 2m−2 时，剩余 2pm−1−jp ≥ 2pm−1−(2m−2)p = 2p−1，故第 j+1 组总能抽出（每轮剩余个数下界恰为 2p−1）；抽得第 2m−1 组后剩余 2pm−1−(2m−1)p = p−1 < 2p−1，过程终止。于是恰好得到 2m−1 组 G₁,…,G_{2m−1}，总组数为 2m−1，每组恰含 p 个数，且每组元素和 s_i 满足 p | s_i（i = 1,…,2m−1）。

第二步（构造归纳数组）。由 D3(a)，对每个 i，p | s_i 推出 s_i = p·b_i，b_i ∈ Z。于是 b₁,…,b_{2m−1} 构成恰有 2m−1 个整数的数组，归纳假设（结论对 m 成立：任意 2m−1 个整数中存在 m 个其和被 m 整除）适用：存在指标 i₁<…<i_m，使 m | Σ_{j=1}^m b_{i_j}，即 Σ_{j=1}^m b_{i_j} = m·c（c ∈ Z，整除定义之商）。

第三步（回代）。取 S = ∪_{j=1}^m G_{i_j}；各组互不相交（每次抽取即从剩余数中移除已用数），故 S 恰含 pm = n 个元素，其元素和 Σ_{x∈S} x = Σ_{j=1}^m s_{i_j} = Σ_{j=1}^m p·b_{i_j} = p·(m·c) = n·c，故 n | Σ_{x∈S} x。即给定 2n−1 个整数中存在 n 个其和被 n 整除。□


## B3 头号定理与最优性

令 P(n) 表示命题：任意 2n−1 个整数 a_1,…,a_{2n−1} 中，存在 n 个整数，其和是 n 的倍数。用强归纳证明 P(n) 对一切 n ≥ 1 成立。

基始 n = 1：2·1−1 = 1，从唯一的一个整数 a_1 中取出它本身，其和 a_1 被 1 整除，故 P(1) 成立。

归纳步：设 n ≥ 2，且 P(m) 对一切 1 ≤ m < n 已成立。取任意 2n−1 个整数 a_1,…,a_{2n−1}，并取 n 的一个素因子 p，分两类：
— 若 n = p 为素数：由块1的结论：素数情形已证（任意 2p−1 个整数中有 p 个，其和是 p 的倍数），故 P(n) 成立；
— 若 n = p·m 为合数，即 m ≥ 2，此时 1 < m < n：由块2的结论：合成情形已证（n = p·m 时由素数情形与对 m 的归纳假设推出）。此处"对 m 的归纳假设"正是强归纳假设 P(m)（因 m < n），故 P(n) 成立。
以上两类的并集覆盖一切 n ≥ 2（任何大于 1 的整数要么是素数要么是合数），由强归纳原理，P(n) 对一切 n ≥ 1 成立。

最优性：2n−1 是保证该性质的最小个数。构造 2n−2 个整数：n−1 个 0 与 n−1 个 1（n = 1 时该构造为空集，自然取不出任何 1 个数，性质同样失败）。任取其中 n 个：设取到 k 个 1，则取到 n−k 个 0。因 1 至多 n−1 个，有 k ≤ n−1；因 0 至多 n−1 个，有 n−k ≤ n−1，即 k ≥ 1。故 1 ≤ k ≤ n−1，而这 n 个数之和恰为 k，满足 1 ≤ k < n，不被 n 整除。于是这 2n−2 个整数中不存在 n 个整数使其和为 n 的倍数，而 2n−1 个整数（由已证结论）必有这样的 n 个，故 2n−1 为最优。∎
