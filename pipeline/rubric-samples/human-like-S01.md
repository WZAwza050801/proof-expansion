# 样稿 H（human-like）：S01 EGZ 素数情形（S1 步）

- 内容：完整写出 S01 脊柱 S1 的素数情形论证，数学正确性与样稿 A 完全相同（C = 4，G = 4，R = 4）

---

设 p 为素数，给定 a_1, …, a_{2p−1} ∈ F_p。要找 p 个下标 I，使 Σ_{i∈I} a_i ≡ 0 (mod p)。

考虑 2p−1 个变量 x_1, …, x_{2p−1}，定义两个多项式

f = Σ_i x_i^{p−1}，  g = Σ_i a_i x_i^{p−1}。

它们公共零点的意义如下：按 D2，每个 x_i^{p−1} 只能取 0 或 1，且取 1 当且仅当 x_i ≠ 0。所以 f(x) ≡ 0 意味着非零分量个数模 p 为 0；这个个数在 1 到 2p−1 之间，故只能是 p。同时 g(x) ≡ 0 给出 Σ_{x_i≠0} a_i ≡ 0。换句话说，一个非零公共零点恰好对应一组"p 个元素、和 ≡ 0 (mod p)"的下标。于是只需证明非零公共零点存在。

两个多项式的次数之和是 2(p−1)，小于变量个数 2p−1，满足 D1 的度数条件，所以公共零点总数 N ≡ 0 (mod p)。而原点 (0, …, 0) 显然是一个公共零点，N ≥ 1；N 又是 p 的倍数，故 N ≥ p > 1，必存在非零公共零点。取其非零分量下标集 I，则 |I| = p 且 Σ_{i∈I} a_i ≡ 0 (mod p)。证毕。
