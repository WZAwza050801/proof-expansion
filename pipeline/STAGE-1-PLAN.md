## 0. 阶段目标（一句话）

停用旧的"诚实/依赖审计"评分，把**任务定义、出题模板、评分规范**三样东西，统一对齐到同一个目标：**给定不完整但结构化的证明思路，补成完整、严谨、可读的证明**。

## 1. 核心共识（本阶段的输入，已与研究者对齐，不再讨论）

1. **任务本质** = 证明补全/扩写，不是独立证明能力。
2. **评价三维**：① 证明正确性（最基本、门槛）② 学术写作质量 ③ 人类可读性（反"AI 味"）。
3. **终极任务模板** = Seidel charter：`P0–P7 脊柱 + completion test + 六态 claim + §7 写作纪律`。
4. **出题来源** = "已知定理、但证明思路去答案化后变模糊"，目标是"模型会一点但没背过完整证明思路"；前沿 open problem 只作天花板探针，不作区分度题。
5. **天花板探针 vs 窄缝题要分开**：Seidel 级 = 测上限；窄缝题 = 测 A/B 差异。

## 2. 做什么（4 个子任务，各有产出 + 验收标准）

### 1.1 重写任务定义与成功标准（operator）
- **产出**：改写 `experiment-design.md` 的「任务定义 + 成功标准」两节。
- **内容**：任务 = 证明补全；三类题分工（探针 / 窄缝 / 秒杀题排除）；成功标准从"提示词有效性"改为"补全质量提升"。
- **验收**：三句话能说清——考什么、不考什么、什么算成功。

### 1.2 出题模板（供 Terra 用）
- **产出**：`prompt-terra-problem-curator.md` v2，外加 2–3 道**蒸馏样题包**。
- **内容**（从 Seidel charter 提炼，不是照抄）：
  - 题包格式 = 定理陈述 + 分步脊柱（每步附 completion test）+ 六态 claim 约定 + 写作纪律；
  - **去答案化规则**：定理可以已知，但证明思路必须模糊化（抽掉关键引理名、人名、中间构造）；
  - **窄缝标定字段**：每题标注"预计模型独立可解度"（高/中/低），供预测试对照。
- **验收**：拿样题问模型，模型"见过定理、但补不出完整思路"——即落在窄缝内。

### 1.3 评价规范（供 judge 用）
- **产出**：`prompt-gpt56sol-reviewer.md` v2 + 新权重表。
- **内容**：
  - 正确性 = 门槛（一票否决），不再是 15% 低权重；
  - 学术写作 = 连贯性、术语规范、论证完整度；
  - 人类可读性 = 拆成可客观数出的子项（有无套话堆砌、是否自然连贯、是否为凑格式重复、公式/文字比例），**不让评委直接判"AI 味"**（评委自己也是 AI，有偏差）。
- **验收**：构造两篇"正确性相同、一篇像人一篇像 AI"的样稿，新评分能稳定拉开可读性分差。

### 1.4 写手提示词方向（仅记录，本阶段不冻结）
- **产出**：`prompt-skill-writer` v0.4 重写方向说明。
- **内容**：把"诚实→停止"改为"诚实→推进"——采纳 charter 的 `CANDIDATE` / `PROVED-IN-PROJECT` 与"最小 blocker + 最强已证定理"，让写手在补不齐时继续做能做的部分。
- **验收**：方向说明写清"何时该停、何时必须继续、两者边界在哪"。

## 3. 顺序与依赖

```
1.1（先定任务）──► 1.2（出题模板，供 Terra）   ──► 1.4（写手方向，最后，因为要服务于 1.3 的可读性）
              └──► 1.3（评价规范，供 judge）   ──┘
```

- 1.1 先做：任务没定，出题和评分都是空谈。
- 1.2、1.3 可并行，但都要在 1.1 之后。
- 1.4 放最后：写手提示词要照着新评分（1.3）的"可读性/正确性"去改，不能反过来。

## 4. 本阶段**不做**的事（边界）

- 不开正式轮、不做大规模 A/B；
- 不让 Terra 批量出题（先只出 2–3 道样题验证模板）；
- 不修 token 分账、不改 preset reasoning 档位（那是阶段 3）；
- 不冻结 v0.4 草稿（等 1.3 评分定完再定写手方向）。
