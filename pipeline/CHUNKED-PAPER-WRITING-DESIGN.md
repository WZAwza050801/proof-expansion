# 分块撰写与拼接：论文写作 Agent 的上下文控制设计

- 日期：2026-08-18
- 状态：设计稿（论文写作 agent 的关键一环；与 `experiment-design.md` §1.0b 的"题目粒度 = 一个基本步骤"互为表里）
- 模板参照：桌面 `seidel_conjecture_distilled_work_charter.md`（P0–P7 脊柱＋completion test＋六态账本＋§7 写作纪律）

## 1. 一句话

长论文不放进一个上下文里写：按证明结构切成块，每块用局部上下文单独撰写，最后按脊柱顺序拼接粘合成论文。**成本几乎不增，省的是上下文控制。**

## 2. 切割（截断/分组）

- 块 = 一个证明义务 / 一个"基本步骤"（charter P0–P7 的粒度；由研究者自己的步骤切割决定）。
- 切割时先立全局约定卡（P0）：符号、记号、系数、对象命名——全论文唯一，块间一致。
- 每块标注它与前块的依赖（哪些结论是它的前置），形成 DAG；无环、可按拓扑序撰写。

## 3. 块接口契约（每块四进三出）

输入（局部上下文，**不携带论文其余部分**）：

1. 全局约定卡（精简版，全块共用，保证符号一致）；
2. 前置结论摘要（"第 k 块已证：……"的引用句，六态 = PROVED-IN-PROJECT）；
3. 允许依赖（精确陈述，无名号无证明）；
4. 本块义务（objective ＋ completion test）。

输出：

1. 本块正文（自然写作；**不复述背景、不重复全局约定**——否则拼接后论文满是重复段）；
2. 结论声明（一句可被后块引用的"已证结论"＋六态）；
3. 依赖与未决标注（引用了哪些前置块/允许依赖；若有 blocker：最小 blocker＋最强已证定理）。

## 4. 拼接（最终粘成论文）

- 按脊柱顺序粘合各块正文；每块开头不带背景段（写作纪律第 1 条已含）。
- **确定性一致性检查（代码，不消耗 LLM）**：
  1. 符号一致性：同一符号在任意两块同义（约定卡为唯一权威）；
  2. 引用完整性：每块的"依赖"都能对上前置块结论或允许依赖（无孤儿断言）；
  3. 结论链闭合：最后一块的结论 = 论文头号定理，无悬空义务；
  4. 重复检测：块间大段相同文本（背景复述）报警并交由拼接器删除。
- **全局 claim 账本**（六态）作为跨块状态：每块写完后更新账本，后续块只读账本——账本就是块与块之间的"接口状态"。

## 5. 为什么成本几乎不增（本设计的核心论断）

- **单次生成**：总产出 token ≈ 一次写完（分块常更省：局部上下文不诱发无关内容）；单次调用窗口小，规避截断与长上下文注意力稀释（lost-in-the-middle）。
- **多轮迭代写作**（草稿→修改，agent 的常态）：单一大上下文每轮重读整个前缀，O(n²)；分块每轮只重读本块，O(n)——**实打实省 token**。
- **并行**：DAG 中互不依赖的块可并行撰写，墙钟时间大幅下降，总 token 不变。
- 额外开销只有：块接口的少量重复（约定卡/前置摘要）＋拼接检查——与正文规模相比可忽略。

## 6. 与测评实验的关系（变量不混淆）

- **块级 = 现有测评单元**：一个题包 = 一块；A/B 提示词对比在块级做（G/R/L/C + 失败模式）。B 提示词中的"不复述背景、引用前置结论、六态标注、最小 blocker"正是分块写作所需的块接口纪律。
- **拼接级 = 新评价轴（另行实验）**：拼接质量用确定性检查器＋一次全局 judge 读（全局连贯、无重复、符号一致）。**不得把拼接质量混进块级 A/B 分数**——否则"提示词"与"拼接器"两个变量混淆。
- 论文写作 agent 的完整形态 = Terra 切块 → 逐块补全（A/B 写手）→ 拼接＋一致性检查 → 全局审读。本仓库当前实验负责"逐块补全"这一环的提示词优化；拼接机制属于基础设施（阶段 3+）与后续局部真实材料试验（README 阶段 4/5）。
