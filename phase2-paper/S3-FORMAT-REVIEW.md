# S3 格式审查报告（模板与规范）

- 阶段：DESIGN.md §4.4 S3——论文级格式审查、调整、输出。
- **产物形态（规则④）**：本阶段的 agent/人产物是**报告清单**，不是论文正文。确定性编辑由脚本机械执行；涉数学内容的条目按清单**路由回 S1 对应块**重写，论文级不直接改证明。
- 过门：报告**零未决项**（每条要么已机械执行，要么已路由回块并重过 G2a）。

## 检查类目（每条：位置｜问题｜处置｜状态[已决/未决/回块]）

1. **编号与角标**：定理类编号连续性；`\ref`/`\eqref` 是否都指向正确目标（错位引用是数学错误，回块）；`\S` 引用与节标题一致。
2. **状态标注呈现**：`[STATUS: X]` 的最终形态（脚注/边注/行内）是否全篇统一；六态语义未被格式转换改变（回块）。
3. **排版级**：overfull/underfull hbox；显示公式编号策略；amscd 图幅面；脚注与边注不溢出。
4. **机械编辑（脚本可执行，白名单）**：`\newtheorem` 去重后的残留；空白/标点规范化；`\label` 命名一致性；重复句删除（仅当与 S2 指令的 edits 清单一致）。
5. **结构**：节标题信息量（Step 2 测试）；引言/结论占位是否已由小派发/人工填充；Roadmap 存在。
6. **交叉一致性**：符号与约定卡；D 编号引用只在卷宗允许范围内。
7. **节点引用转换完整性（2026-08-21 补）**：正文 NXX 提及总数 vs 已转换数（`\Nref` 解析＋xrefs，
   计数见组装报告 `nrefs`/`xrefs` 字段）。未转换余额的处置：调度编辑出**出现级** find/replace 清单
   （短语须在目标块恰好出现一次），或回块补 `\Nref` 标注（splicer v0.4）；无 label 的提及路由回块。
8. **参考文献表（2026-08-21 补，此前无工位）**：`thebibliography` 条目与 `sources/DOSSIERS.md`
   逐条一致（arXiv 号/作者/定理号——dossier 已过 API 复核）；D6 的 Bai–Seidel 缺稿按诚实口径呈现
   （unpublished/私人通信级别），不得伪造出处；Wu 组进行中工作按 seminar/talk 形式引用。

## 处置路由（硬规则）

- 拼写/标点/空白/编号呈现 → **机械执行**（脚本，白名单内）；
- 措辞/衔接/标题 → 列 edits 清单，**下一轮组装**时生效；
- 任何触及数学内容（符号语义、公式、假设、结论范围、状态语义）→ **回 S1 对应块**，重过 G2a 断言＋探针；
- 拿不准 → questions，按 `common/ASK-HUMAN-CONVENTION.md` 问人。
