## 一、八阶段总览（顺序即证明顺序）

| 阶段 | 干什么 | 节点 | 数量 |
|---|---|---|---|
| **P0** 范围与约定门 | 冻结范围、钉死全部方差约定、核验外部来源、写出诚实定理 | N00 N01 N02 N03 | 4 |
| **P1** 形式代数桥 | 纯代数侧：bar 分解 → 对角分解 → Hochschild 识别 | N04 N05 N06 | 3 |
| **P2** stopped 几何 | 几何侧：stopped 模型 → 两个 Yoneda 双模 → split-gen → 去 stop | N07–N14 | 8 |
| **P3** 无穷远控制 | 分析侧：0/1/2 参数估计、no-escape、ends 与 cofinality | N15 N16 N17 N18 | 4 |
| **P4** 乘积↔不动点 | 链级比较：生成元→方程能量→紧性指标→定向线→continuation | N19 N20 N21 N22 N23 | 5 |
| **P5** 认同 Seidel CO | 证明我们造的映射**就是** Seidel 的穿孔圆盘 CO | N24 N25 | 2 |
| **P6** telescope 恢复 | 稳定化 + 有限阶段回收 | N26 N27 N28 | 3 |
| **P7** 对偶与范围冻结 | 完美性→OC 对偶→四类核对→三类自同构阶梯→冻结最终定理 | N29–N37 | 9 |

目标定理（N03"诚实定理"，一切的根）：

$$CO_{\phi,\delta,\varepsilon}: HF^*(\phi;\delta,\varepsilon) \longrightarrow H^*RHom_{A^e}(A, P_{\phi,\delta,\varepsilon}) \quad\text{是拟同构}$$

即 Seidel 猜想：不动点 Floer 同调 ≅ 带扰动双模的 Hochschild 同调，且 Seidel 的扭曲
closed-open 映射实现这个同构。

## 二、架构：两座塔 + 一根分析脊柱，在中途汇合

```
                    N03 诚实定理（P0 的出口 = 一切的根）
                   /                              \
        ┌── 代数塔（P1，纯形式）──┐        ┌── 几何塔（P2，要造东西）──┐
        │  N04 有限 bar            │        │  N07 粗 stopped 模型       │
        │   ↓                     │        │   ↓        ↓              │
        │  N05 分解对角            │        │  N08 对角   N10 fine 模型  │
        │   ↓                     │        │   双模     与 split-gen    │
        │  N06 Hochschild 识别    │        │   ↓   N14 有限对 Floer 数据 │
        │  （RHom 的代数侧实现）    │        │   ↓   ↓                   │
        └──────────┬──────────────┘        │  N09 graph 双模            │
                   │                       │   ↓                       │
                   │      N11 graph 右正交 → N12 两两去 stop            │
                   │           └──────┬────────────────┘               │
                   │                  ↓                                │
                   ══════════ N13 几何到 Hochschild ══════════  ← 两塔在此合流
                                          │
              ┌─── 分析脊柱（P3，估计）──┐ │
              │ N15 零参数 → N16 一参数    │ │
              │   → N17 二参数 → N18 ends  │ │   （脊柱独立生长，
              └─────────────┬─────────────┘    在 P4/P5 处并入主线）
                            ↓
        P4 链级比较：N19 生成元 → N20 方程能量 → N21 紧性指标
                            → N22 定向线 → N23 continuation
                            ↓
              N24 几何 Yoneda 映射 → N25 ≡ Seidel CO   ← 全证明的心脏
                            ↓
        P6：N26 telescope → N27 终端稳定 → N28 有限阶段恢复
                            ↓
        P7：N29 完美性 → N30 对偶平移 → N31 四类核对
              → N32/N33/N34 三类自同构阶梯（ν^k / 迭代 / 一般）
              → N35 冻结系数 → N36 写作账本 → N37 最终定理
```

顺序逻辑是经典的**两边夹**：

- 左塔（P1）只做形式代数——bar 分解是纯范畴论，不碰几何，三步到 HH；
- 右塔（P2）真造几何对象——stopped wrapped Fukaya 范畴、对角与 graph 的 Yoneda 双模、
  split-generation（N10）、stop removal（N12）；
- 两塔在 **N13** 汇合：几何对象算出的 = 代数塔算出的；
- P3 的分析（N15–N18）不产新对象，产**许可**——估计在无穷远不逃逸、只用有限对、参数族受控；
- P4 把几何模型换成不动点模型（五特征逐项对齐），P5 说"这就是 Seidel 的 CO"，
  P6 用 telescope 收回有限阶段，P7 做对偶、查特例、逐级放宽范围、落纸。

## 三、上下层引用关系（必须遵守）

**下层的证明和推进必须参考上层**——这不是风格建议，是流水线的硬约束，五条不变量共同保证：

| | 不变量 | 保证什么 |
|---|---|---|
| **I1** | 依赖未落盘 ⇒ 拒发 | 推进参考上层：前置没写完，下层任务书根本发不出来 |
| **I3** | 【前置结论】只能是上游块已落盘的原文 | 任务书里的前置结论由程序从真实块文件拼装，模型无法凭空假设 |
| **I5** | 声明的每个 dep 必须被正文实际引用 | 证明参考上层：列了前置却不用（自己从头推）会被 `status` 标记违规 |
| **I2** | 有效状态 = worst(自己, 所有前置) | 上游降级（如 CONDITIONAL），下游继承，headline 诚实 |
| **I4** | 人门档位 = 取严(confirm_policy, 污染半径) | 承重节点的人检不可被 yolo 跳过 |

I3 与 I5 是一对：**I3 管"引用的东西是真是假"（N19 引的是空气，被 I3 抓），
I5 管"该引用的是不是真引了"（列了前置却绕开重推，被 I5 抓）。**

块内引用格式：`由 N08 的结论：……`。`splice.py` 再做反向核对（引用的必须在 deps 内）。

## 四、结构细节（推进时值得知道）

1. **P0 不是证明，是承重墙。** N00–N03 无一数学断言，全是范围/约定/来源/陈述——但污染半径
   34–36/37，写错则后面 34 块全废。调度器把这四层全设 manual。
2. **证明心脏只有 2 个节点**：N24（造几何 Yoneda 映射）+ N25（证它 ≡ Seidel CO）。
   P1–P4 的十二个节点都在为这两步扫障。N25 也是审图抓出漏边最多的节点。
3. **P7 的 N32/N33/N34 是三个推广阶梯**（ν^k → 迭代可容许 → 一般自同构），每级是逐条
   核对假设清单而非新证明，可并行（同层 L20）。
4. **L9–L19 的 11 层单链对应 P3→P4 骨干**：估计→比较→认同→收回→对偶，数学本身不给并行
   空间。审图确认除 N27←N26、N29←N28 两条可议假边外全是真依赖。
5. **粒度标准**：一节点 = 一次 LLM 调用能完成 = 一句话结论可被下游引用。
   例：N19 只证"生成元双射"，不证"复形同构"——同构由 N22 之后的链合给。
